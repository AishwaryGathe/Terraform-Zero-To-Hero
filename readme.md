## 🚀 Overview

This repository provides a clean, practical path to learning Terraform from scratch and understanding how to build production-ready Infrastructure-as-Code. The goal is simple: help you learn Terraform the way it's actually used in real DevOps and cloud engineering work — structured modules, proper state management, reusable components, and environment separation.

---

## 📘 What This Repository Covers

- Terraform setup and workflow  
- Providers, resources, and data sources  
- Variables, outputs, and locals  
- Remote and local state management  
- Building and using modules  
- Structuring multi-environment projects  
- Recommended folder structures and patterns  
- Clean, scalable IaC best practices  

This is designed to be a practical reference, not a theoretical one.

## ⚡ Getting Started

Clone the repository:

```bash
git clone https://github.com/AishwaryGathe/Terraform-Zero-To-Hero.git
cd Terraform-Zero-To-Hero
````

Run any example:

```bash
terraform init
terraform plan
terraform apply
```

Break things, fix them, understand what happened — that’s how you become good at Terraform.
